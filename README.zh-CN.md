# FlyDrones 中文试玩

**[点这里开始玩](https://lxy1992.github.io/FlyDrones-zh/)** · [原作 SpikeCalls/FlyDrones](https://github.com/SpikeCalls/FlyDrones)

这是原项目浏览器演示的简体中文分支。菜单、手势提示、神经通路、图表标签、鼠标提示和小游戏已本地化，保留原来的场景风格。

## 30 秒上手

1. 打开网页，等待神经网络预热；默认自动演示。
2. 按 **1** 张掌上升，按 **2** 握拳悬停，按 **6** 放手下降。
3. 按 **S** 进入拍打挑战，等它起飞稳定后再按 **S** 挥拍；看它能否躲开。刚进入模式的前几秒不接受挥拍，这是原作的起飞等待逻辑。

其他玩法：按 **3 / 4** 向左 / 向右，按 **5** 模拟手掌快速靠近；点击右侧神经元群，给它 1 秒的 150 Hz 刺激；点击“椅子避障”观察减速和转向。

| 操作 | 效果 |
| --- | --- |
| 空格 / R | 重新开始自动演示 |
| N | 切换白天 / 夜晚 |
| C | 切换环绕、跟随、机载相机 |
| M | 开关音效（默认关闭） |
| 拖动场景 | 调整观察视角 |

桌面浏览器体验更合适；窄屏采用上下排列，可往下滚动查看面板和按钮。

## 它究竟在模拟什么？

网页在本机浏览器中实时运行 **850 个神经元、4,928 条连接的 MiniFly 人工连接模型**，把模拟视觉输入送入脉冲神经网络，再把输出映射为虚拟无人机的运动。右侧图表来自运行中的模型，并非预录视频。

它**不是完整果蝇连接组，也不是此前 Brian2 糖刺激实验的全脑模型**；机顶果蝇是吉祥物，网页不会连接真实无人机。“静态网站”只表示服务器发送网页文件，不表示网页没有计算。

本分支没有训练网络、调整生物参数、接入真实飞控或下载完整脑数据。界面中的计算速度是原作对引擎计算步骤的计时显示，不是现实无人机飞行性能证明。

## 摄像头与联网

不开摄像头也能完整体验按钮和键盘玩法。只有主动点击“摄像头手势”并允许浏览器权限，网页才会请求摄像头。

原作的手势识别通过 jsDelivr 加载固定版本 `@mediapipe/tasks-vision@0.10.14`，从 Google Storage 加载手部模型；图像在浏览器本地处理。网络无法连接这些服务时，可继续用按钮玩。开启后关闭此页面即可停止摄像头。本次部署验证未开启摄像头，也未验证手部识别效果。

普通仿真用到的 Three.js 和 MiniFly 数据已随网页附带，不需要 Python、Conda、GPU 服务或付费 API。

## 本地打开

需要 Python 3，不安装任何 Python 包：

```sh
git clone https://github.com/lxy1992/FlyDrones-zh.git
cd FlyDrones-zh
./run_local.sh
```

浏览器打开 `http://127.0.0.1:8765/`。需要换端口时运行 `./run_local.sh 8080`。不要直接双击 HTML，因为浏览器会限制本地文件之间的模块加载。
