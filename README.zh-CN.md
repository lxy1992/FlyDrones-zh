# FlyDrones 经典版中文试玩

**[点这里开始玩](https://lxy1992.github.io/FlyDrones-zh/)** · [原作 SpikeCalls/FlyDrones](https://github.com/SpikeCalls/FlyDrones)

这是作者大幅改版前的浏览器演示：**霓虹线框房间、简洁四旋翼、原版视角和布局，没有机顶大苍蝇**。只做简体中文展示，不混入 2.0 的写实卧室或吉祥物。

“经典版”指上游提交 **`2409f08c03f3e4c9deda3f10996f37a031014c02`**，并非声称作者发布过正式的 `v1.0` 标签。该页面与 `4faf98e`（Live demo 2.0）之前的上一版一致。

## 30 秒上手

1. 打开网页，等待神经网络预热；默认自动演示。
2. 按 **1** 张掌上升，按 **2** 握拳悬停，按 **6** 放手下降。
3. 按 **5** 模拟物体快速靠近，观察巨纤维触发逃逸；或点击“椅子避障”。

| 操作 | 效果 |
| --- | --- |
| 3 / 4 | 手向左 / 向右，改变模拟视觉信号 |
| 空格 / R | 重新开始自动演示 |
| 拖动场景 | 调整观察视角 |
| 摄像头手势 | 主动授权后，使用本机手势识别 |

恢复旧版也意味着没有 2.0 新增的拍打挑战、点击刺激神经元、昼夜与视角切换按钮。右侧神经网络和放电图仍在实时计算。

## 它究竟在模拟什么？

网页在本机浏览器中运行 **850 个神经元、4,928 条连接的 MiniFly 人工连接模型**，把模拟视觉输入送入脉冲神经网络，再把输出映射为虚拟无人机运动，不是预录视频。

它不是完整果蝇连接组，也不是 Brian2 糖刺激实验的全脑模型，不会连接真实无人机。“静态网站”只是服务器提供文件，计算仍然在浏览器里进行。

## 摄像头与联网

按钮和键盘玩法不需要摄像头。只有主动点击“摄像头手势”并允许浏览器权限，网页才会请求摄像头。

手势识别沿用原作：从 jsDelivr 加载 `@mediapipe/tasks-vision@0.10.14`，从 Google Storage 加载手部模型；图像在浏览器本地处理。访问这些服务失败时可继续用按钮玩。关闭页面可停止摄像头。本次未开启摄像头验证。

普通仿真所需的 Three.js 和 MiniFly 数据已随网页附带，不需要 Python 环境、GPU 服务或付费 API。

## 本地运行与发布

需要 Python 3，不安装 Python 包：

```sh
git clone https://github.com/lxy1992/FlyDrones-zh.git
cd FlyDrones-zh
./run_local.sh
```

浏览器打开 `http://127.0.0.1:8765/`。换端口用 `./run_local.sh 8080`；不要直接双击 HTML，因为浏览器会限制本地文件之间的模块加载。

推送到 `main` 后，`Chinese GitHub Pages` 工作流先运行检查，再仅发布 `docs/`。Pages 的发布来源保持 **GitHub Actions**。本地可用 Node.js 22 执行 `npm test`，无需安装 npm 依赖。

## 版本锁定与验证

- 页面、场景代码、引擎、数据和分享图片恢复到上述旧版提交。Python 包未修改。
- 引擎与网络数据固定 SHA-256；渲染和飞行动画的源代码也固定摘要，除中文标签与字体外必须与旧版相同，避免下次又带入上游新造型。
- 展示翻译在 `docs/index.html`、`docs/live/app.js` 和 `docs/live/zh-CN.js`；模型方程、参数、权重、刺激和计算规则保持该旧版原样。
- 模型回归检查覆盖张掌上升、握拳悬停、放手下降、快速靠近触发逃逸及演示无碰撞。这不等于真实无人机验证。

此前首次部署误选了已加入大苍蝇和写实卧室的新版；现按用户参考截图恢复改版前的整个网页，而不是只隐藏苍蝇。使用带版本的入口和模块地址，避免浏览器混用新旧缓存。
